# 🚀 Старт работы с boom-cmd

Первое, что читает AI-разработчик после доступа к репозиторию. Что сделать в
первые 30 секунд и какие правила держать в голове всегда.

> **Командный центр БумБастик** — внутренний BizOps-пульт (обзор «где мы и куда
> идём», не таск-трекер) для владельцев сети игровых парков. PWA, mobile-first
> под iPhone. Стек: Vue 3 (`<script setup>`, JS) + Vite + Tailwind 3 + lucide.
> Продукт в `src/`, документы в `docs/`.

## Чек-лист на старт
1. **`docs/PRODUCT-PRINCIPLES-boom-cmd.md`** — keystone: ДНК продукта, IA, модель данных, фазы. Главнее ТЗ.
2. **`docs/DESIGN-STANDARD-boom-cmd.md`** — источник истины по визуалу (тема, токены, Apple HIG, правило текста/цвета, шапка, фильтр).
3. **`docs/00_NAVIGATOR-boom-cmd.md`** — карта: стек, репо, инфра (в т.ч. PWA/SW), запреты, статус фаз.
4. Остальные `docs/` (`TZ-*`, `AUTH`) — **не читай заранее**, подтягивай по задаче. Экономь контекст.
5. Скажи коротко «готов» — жди задание.

## Правила в голове (всегда)
- **Цвет — только токены** `var(--…)` из `DESIGN-STANDARD`. Хардкод hex запрещён (кроме `main.css`).
- **Монохром по умолчанию; цвет только функциональный:** срочный приоритет (`--negative`), активная вкладка (`--accent`), данные графиков. Всё остальное — серое. **Текст всегда монохромный.** (Старая «LEGO-палитра» из ранних версий отменена.)
- **Тема светлая** по умолчанию; тёмная — будущий свап токенов, не дефолт.
- **Mobile-first iPhone, Apple HIG:** tab bar внизу; шапка — **large-title-collapse** (крупный заголовок в потоке + компактная стики при скролле, `COLLAPSE_AT=28`), заголовок **центрированный** в обоих состояниях; ≥44pt; safe-area `env()`; `backdrop-blur` через Tailwind. Десктоп — колонка ~430px по центру.
- **`base: '/boom-cmd/'`** прошит в `vite.config`/`manifest.json`/`sw.js`/`index.html` — менять только синхронно.
- **Стек не меняем:** Vue 3 + Vite + Tailwind **3** + lucide, PWA вручную (`manifest`+`sw.js`). Без TypeScript, Tailwind v4, vite-plugin-pwa, drag-библиотек.
- **Фронт read-only.** Источник изолирован в `useProjects.js`; авторизация + живой источник = **gated Apps Script** (`docs/AUTH`, фаза 4); URL/креды — в env/sessionStorage, не в репо. Данные EN, UI RU.
- **IA:** 4 вкладки — **Главная (командная дека) / Аналитика / Проекты / Материалы**. Глобальный парк-контекст `useParkContext` (`'network'` | id парка) с **чистым разделением**: «Вся сеть» = только общесетевые, вид парка = только его; **бейджей scope на карточках нет**. Навигация — `useAppNav` (вкладка + `subView:'parks'`). Справочник парков — `src/data/parks.js`.
- **PWA/SW:** версионированный кэш + `skipWaiting`/`clients.claim` + чистка + network-first навигаций; регистрация **только в PROD**; есть ручная кнопка hard-reload (страховка). Не ломать.
- **Иерархия истины:** `PRODUCT-PRINCIPLES` (продукт/IA) → `DESIGN-STANDARD` (визуал) → `00_NAVIGATOR` (стек/инфра/фазы) → `TZ-*`. При конфликте — **сигналь, не додумывай.**
- **Оболочку, шапку, парк-контекст, Проекты, SW** не ломать без причины (фазы 0–3.4 приняты).

## Сборка и проверка (прогоняй сам)
Есть доступ к ПК с `node_modules` — **прогоняй и докладывай** (это заменяет «отдай архив»):
- `npm run build` — зелёный, размеры в норме;
- `npm run dev` — ручная проверка состояний (loading/error/empty, модалка, скролл/collapse);
- `grep` — нет хардкода hex в новых файлах; `-webkit-backdrop-filter` есть в собранном CSS; для PWA-правок — плейсхолдер `__BUILD_ID__` в `dist/sw.js` заменён на число.

## Git-workflow (важно)
Репо на Mac, синхронизация — через **GitHub Desktop**. Commit/push делает **владелец**, не ты.
- Правки — файлами (`Edit`/`Write`). **Никаких** `git commit`/`push` от тебя.
- В конце куска — предложение коммита **двумя блоками**: (1) заголовок Conventional Commits `тип(скоуп): описание`; (2) описание 3–5 строк — что и зачем.
- `docs/` в gitignore (не уйдёт в git). Отдельный коммит `docs(public): …` нужен **только если правишь корневой `CLAUDE.md`**.

Пример:
```
feat(filter): чистое разделение парк-фильтра — Вся сеть | парк

- useParkContext: 'network' | id; isNetwork; фильтр в ProjectsScreen
- ParkBadge убран — scope задаёт фильтр
- мок/нормализация 'all' → 'network'
```

## Стиль ответа
Коротко, по-русски, без преамбул.
- **Значимая задача** (ТЗ фазы, модуль): сначала подтверди понимание + риски/развилки с рекомендациями + план, **жди «принято»** — потом код.
- **Мелкая правка:** делай сразу; при неоднозначности — 1–2 коротких уточнения.
